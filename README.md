# 🌟 SKKU brAIn Cinematic Lottery Web Application

> **성균관대학교 인공지능 학회 brAIn**을 위해 특별히 맞춤 제작된 프리미엄 **시네마틱 무작위 추첨 웹 애플리케이션**입니다.  
> 세련된 다크 에메랄드 테마의 글래스모피즘 HUD 인터페이스와 압도적인 웅장함의 영상 전환 효과, 브라우저 실시간 오디오 합성 엔진 및 화려한 캔버스 콘페티 시스템이 내장되어 있습니다.

---

## 🚀 주요 특징 (Key Features)

### 1. 시네마틱 빌드업 & 정확한 타이밍 싱크 (Cinematic Video Climax)
- **정밀한 9.5초 프레임 컷오프**: 무작위 셔플링과 전환용 비디오(`buildup.mp4`)의 절정 지점인 `9.5초`를 `requestAnimationFrame` 루프를 활용해 60Hz 빈도로 모니터링하며, 정확한 클라이맥스 순간에 전체 화면 플래시 전환 및 당첨 효과를 트리거합니다.
- **초고속 셔플러**: 비디오 재생 중 후보군 목록의 이름들을 초고속(60ms 간격)으로 실시간 셔플링하여 극적인 긴장감을 유도합니다.

### 2. 고품격 디자인 & 인터페이스 (Elegant Cyber-Green Theme)
- **다크 에메랄드/민트 테마**: brAIn 학회 로고의 오리지널 컬러 아이덴티티를 살린 감각적인 그라데이션 바탕과 테두리 발광 효과를 채용했습니다.
- **글래스모피즘 패널**: 전반적으로 흐릿한 투명 유리 효과(Backdrop Blur) 및 사이버네틱 입체감을 구현했습니다.
- **회전하는 과학 링**: 드로우 버튼의 테두리를 구성하는 두 개의 테크놀로지 링이 반대 방향으로 회전하며 프리미엄 연구소 느낌을 자아냅니다.

### 3. 실시간 사운드 및 파티클 엔진 (Synths & Physics Confetti)
- **Web Audio API 오디오 합성**: 무겁고 로딩이 느린 오디오 파일 대신 브라우저 내장 오디오 합성 노드를 활용하여 무작위 클릭음(Plip)과 승리 축하용 C 메이저 공상과학 아르페지오 코드(Dramatic Sci-Fi Chord) 및 화이트노이즈 바람소리를 실시간으로 합성 및 재생합니다.
- **2D 캔버스 물리 콘페티**: 민트, 에메랄드, 골드, 화이트 색상의 다채로운 리본 가루들이 폭죽처럼 뿜어져 나와 회전하고, 중력과 마찰력에 반응하며 하강하는 리얼한 물리 엔진이 탑재되었습니다.

### 4. 편리한 관리 및 설정 기능 (Management & Persistence)
- **실시간 명단 가감 및 상태 토글**: 텍스트 입력창에 쉼표나 개행문자로 이름을 구분하여 즉시 대량으로 명단을 추가할 수 있으며, 불참한 멤버는 토글스위치로 손쉽게 활성/비활성 처리할 수 있습니다.
- **당첨 현황 자동 대장**: 당첨된 인원과 정확한 시각을 실시간 연대순 기록으로 우측 히스토리 보드에 표기합니다.
- **데이터 영구 영속성 (localStorage)**: 브라우저가 종료되거나 페이지를 새로고침 하더라도 현재 참여 인원 설정, 상태값, 옵션 상태, 그리고 이전 당첨 내역들이 손실되지 않고 브라우저 캐시에 영구 유지됩니다.
- **유연한 옵션**: 동영상 빌드업을 건너뛰는 **직행 모드(Skip Video)** 및 동일인 중복 추첨을 제한하는 **중복 불가 모드**를 마우스 클릭만으로 손쉽게 조정할 수 있습니다.

### 5. 특수 로직 (Weighted Probability)
- **지용제님 25% 가중치**: 활성 추첨 대상자 목록에 **지용제**님이 포함된 경우, 수학적 가중치 계산식을 통해 정확하게 **25%의 당첨 확률**을 부여하고 나머지 75%의 확률을 다른 참여자들에게 공평하게 1/N 배분합니다. (대상자가 없거나 홀로 남은 경우 등 비정상 상황 시 안전한 1/N 균등 분배로 자동 복구됩니다.)

## 💻 실행 방법 (How to Run)

본 애플리케이션은 비디오 및 고용량 자산의 미디어 정책(CORS) 보호로 인해 **로컬 웹 서버** 환경에서 실행할 때 가장 매끄럽게 구동됩니다.

### 방법 1. 간편한 데스크톱 런처로 실행 (Windows 사용자용)
바탕화면에 생성되어 있는 🌟 **`brAIn_Lottery.lnk`** 단축아이콘을 더블클릭합니다!
- 백그라운드에서 로컬 파이썬 웹 서버가 조용히 자동 구동됩니다 (포트 충돌 방지 로직 적용).
- 디폴트 브라우저로 [http://localhost:8000](http://localhost:8000) 페이지가 자동으로 열립니다.

### 방법 2. 직접 수동 구동
1. 터미널(CMD / PowerShell 등)을 열어 본 프로젝트 루트 디렉터리로 이동합니다.
2. 아래 명령어를 실행하여 가벼운 파이썬 로컬 웹 서버를 구동합니다:
   ```bash
   python -m http.server 8000
   ```
3. 웹 브라우저를 열고 다음 주소에 접속합니다:
   - **[http://localhost:8000](http://localhost:8000)**

## 🛠️ 기술 스택 (Tech Stack)

- **Language & Core**: Plain HTML5, CSS3, ES6+ Vanilla JavaScript
- **Styling Paradigm**: CSS Variable 기반 테마 토큰, Backdrop Filters, Flexbox & CSS Grid Layout, @keyframes animations
- **Multimedia APIs**: Web Audio API (real-time synthesizer nodes), HTML5 MediaElement API, HTML5 Canvas 2D Context API
- **Persistence**: Window LocalStorage API
